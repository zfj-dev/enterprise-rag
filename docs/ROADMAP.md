# ROADMAP — 求职项目“要加什么”

> 术语见 [CONTEXT.md](../CONTEXT.md);本文件是**计划**,不是词汇表。
> 定位:目标岗位 **AI 应用 / Agent 工程**、面向**国内中小企业**、**主力项目做深**、单人 + 一台 4050(预算有限)、边投边加。

## 部署形态
- **在线 Demo(7×24,给招聘方/身边人真用)**:便宜 **CPU VPS** + **托管嵌入/重排**(DashScope/SiliconFlow)+ DashScope LLM → 无 GPU、成本低。
  - 已接受的取舍:在线版的**文档分块会经托管嵌入 API**。
- **私有化能力(卖点,不常开)**:已有**私有 GPU 节点 + 本地 bge**,打成“**一条命令装进客户内网**”,展示“数据不出内网”。

## 要加的(每项 = MVP + 产出)

| 项 | MVP | 产出(数字 / 交付物) |
|---|---|---|
| **P0 评测** | 自研判据(含期望事实 / 页码 / 拒答)+ **RAGAS 四项**(faithfulness / answer-relevancy / context-precision / recall,judge 固定 **qwen-turbo,temp=0**)+ **RGB 中文全套四能力** | RAGAS 4 数字 + RGB 4 数字(含**拒答率**)+ 一页报告 |
| **P1 Agentic** | ReAct + 3 工具(`KbRetrieve` / `SqlQuery` / `Calculator`)+ 1 步 self-check。**单代理**,不上多代理 | 事实命中 / 延迟**变化** |
| **P2a 上下文** | 会话摘要 + 工具结果清理 | **token 降幅** |
| **P2b MCP**(优先) | 暴露 1–2 个工具为 MCP server | MCP 可被客户端挂载 |
| **P2c 记忆**(最小) | 从会话抽“事实”存表 + 召回 | 跨会话召回示例 |
| **Q9i 成本面板** | per-query token/费用 + 预算上限 | 成本可见 |
| **Q9ii 一键私有化部署** | 一条命令装进客户内网(私有 GPU 节点 / 本地 bge) | 私有化 demo |

## 评测策略(已定,承接 grilling)
- **用途**:以“**业界可比数字**”为主(简历/面试),工程闭环附带。
- **指标**:自研免 LLM 判据(含期望事实 / 页码 / 拒答)+ **RAGAS**;judge **固定 qwen-turbo、temp=0**,报告写明口径。
- **数据集(双轨)**:领域黄金集(自建 → 业务数字)+ **RGB 中文四能力**(→ 业界可比 / 拒答数字);**CRUD-RAG 不做**。
- **优先级**:**抗幻觉(faithfulness)+ 拒答正确** 第一;**延迟**第二(分桶 + 3–5 并发下 P50 / P95 / TTFT)。
- **设施**:**轻量**——一键脚本 + 一页报告;**不做** CI 发版门禁(除非讲成 “eval gate”)。
