# 35: 余额提醒（能查则查 / 查不到明说）

**What to build:** BYOK 用量**照常记账但不纳入硬拦**；余额提醒**尽力覆盖**——厂商能查余额就展示真实余额并提醒，查不到就**明确告知"该厂商不支持余额查询"**，绝不静默省略。

**Blocked by:** 27 per-query 用量记账；28 费用折算 + 价格表

**Status:** ready-for-agent

- [ ] 厂商**提供余额接口**时：查到并展示**真实余额**；低于阈值时给出**提醒**（只提醒、不拦截）
- [ ] 厂商**不提供**该接口时：界面**明确写出"该厂商不支持余额查询"**，不留空、不拿用量冒充余额
- [ ] **我方累计用量**作为**独立维度**照常展示（可审计）
- [ ] 界面与报告**分别标明**"厂商余额"与"我方统计用量"两个数字各自的来源
- [ ] BYOK 用量**不触发** Spec 0005 的硬拦（回归）
