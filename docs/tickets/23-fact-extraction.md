# 23: 写入时异步抽取事实（按用户落库）

**What to build:** 每轮问答**完成后异步**抽出"用户告知的、可跨会话复用的事实"并落库，归属到该用户；**抽取失败一律旁路**，不影响用户拿到回答。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 一轮问答完成后，事实被抽出并**归属到该用户**
- [ ] **抽取失败或超时不影响回答**（回答照常返回、不抛穿、不阻塞下一问）
- [ ] **只抽用户告知的事实**：文档内容与模型自己的回答**都不被抽**（用 stub 输入断言输出集合）
- [ ] 抽取器与存储**从外部注入**，测试确定性、无网络
