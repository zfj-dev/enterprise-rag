# 13: SqlQuery 工具

**What to build:** 代理能回答"每个知识库有多少文档 / 哪些还在处理中 / 某文档多大"这类**元数据**问题，而**注入面按构造消除**。

**Blocked by:** 10 MCP 往返打通 + Calculator 工具

**Status:** ready-for-agent

- [ ] 接受**受限的结构化查询描述**（表 + 字段 + 过滤 + 聚合 + 排序 + 上限），**不接受原始 SQL 文本**
- [ ] 仅可查**文档 / 知识库元数据白名单**；凭证类字段不可达
- [ ] 强制行数上限；只读；属主范围由服务端注入
- [ ] 白名单外的表/字段、越权范围、超限请求均被拒绝（含单测）
