**What to build:** 新会话提问时按相似度召回少量相关事实，作为一块**独立的「已知信息」**注入，**与【参考资料】分开**；记忆**绝不进入来源通道**。

**Blocked by:** 23 写入时异步抽取事实（按用户落库）

**Status:** ready-for-agent

- [ ] 按相似度取 top-k 且有上限；**无相关记忆时零注入**（不塞空块、不占预算）
- [ ] 记忆**不出现在 `sources` 里**，也**不进入检索候选池**
- [ ] **不改变引用校验的结论**（同一条答案，有/无记忆时"是否有来源"的判定一致）
