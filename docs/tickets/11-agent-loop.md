# 11: 代理循环（ReAct）

**What to build:** 给定一个需要多步的问题，代理能**自行选择工具**、把结果回灌、在有上限的步数内给出答案；失控与工具报错时能收敛而不是崩掉。

**Blocked by:** 09 LLM 带工具对话能力；10 MCP 往返打通 + Calculator 工具

**Status:** ready-for-agent

- [ ] 注入脚本化 LLM + stub MCP client 时，产出预期答案与预期步数（**确定性、无网络、不起真 MCP 进程**）
- [ ] 达步数上限时**收敛返回**而非抛穿
- [ ] 工具报错时**降级返回**（不得因单次工具失败而丢弃整个回答）
- [ ] 每步的工具名、参数、结果摘要与耗时写入 trace（可观测）
