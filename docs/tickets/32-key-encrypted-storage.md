# 32: Key 加密落库 + 不回显 + 轮换/删除

**What to build:** 用户能填入并保存自己的 `base_url` / `key` / `model`（存一次跨会话有效），而 key **加密落库**、**从不回显**、可**轮换与删除**。

**Blocked by:** 31 LLM 工厂 + 按请求解析

**Status:** ready-for-agent

- [ ] key **加密落库**；加密密钥来自服务端配置且**不得有默认弱值**
- [ ] 读取接口**只回尾号等非敏感信息**，**任何响应都不含明文 key**（对响应体直接断言）
- [ ] **日志与 trace 永不出现明文 key**
- [ ] 支持**轮换**（旧凭据失效）与**删除**（删除后立即回落全局）
