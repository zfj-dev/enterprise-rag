# 01: 评测核心注入缝

**What to build:** 一条命令即可对任意"问答实现"给出确定的评测数字——评测核心本身不连服务、不调 LLM，**被评对象与裁判都从外部注入**。这是把现有"各脚本各算一套"的评测逻辑收敛成一个可注入核心（预重构）。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 给定黄金集（问题 + 期望事实）与注入的 stub 问答函数，产出一份报告对象，含期望事实命中率
- [ ] 注入 stub 裁判函数时断言结果**确定、无网络、无真实 LLM**
- [ ] 现有端到端判据（期望事实 / 页码 / 引用忠实）改为经该核心调用，不再各脚本自成一套
- [ ] 核心不耦合运行中的服务器（可离线调用）
