# 33: base_url SSRF 防护

**What to build:** 用户自填的 `base_url` 不得把我方服务变成内网跳板——**私网 / 回环 / 非 https 地址一律拒绝**。

**Blocked by:** 32 Key 加密落库 + 不回显 + 轮换/删除

**Status:** ready-for-agent

- [ ] **私网地址**（含回环、链路本地、保留网段）被**拒绝**（含单测）
- [ ] **非 https** 被拒绝（本地开发场景可**显式**放行）
- [ ] 支持域名**白名单**（可配）与请求**超时上限**
- [ ] 拒绝信息明确（看得出是地址不合规，而非"连接失败"）
